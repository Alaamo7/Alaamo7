## How I work

I separate three questions that are often confused:

1. **Does the script compile?**
2. **Does it render and behave coherently on the chart?**
3. **Does the strategy show a robust edge after costs and out-of-sample testing?**

A successful answer to the first two never implies the third. My repositories keep screenshots, test context, limitations, and negative results visible so the work can be reviewed honestly.
