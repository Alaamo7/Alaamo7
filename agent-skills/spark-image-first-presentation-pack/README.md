# Spark Agent — Image-First Presentation Skills Pack

**Status: Manifest** — the pack structure and orchestration order were recovered, but the individual original `SKILL.md` source files are not currently available in the working library.

This pack was derived by reverse-engineering reference presentation decks and formalizing their recurring visual and educational patterns.

## Reference pattern

The analyzed decks used an **Image-First Deck** approach: each slide is primarily a full-slide rendered visual rather than a collection of individually editable PowerPoint elements.

Common characteristics:

- 16:9 layout
- Warm light or grid-paper backgrounds
- Isometric / Technical Illustration / Editorial Infographic style
- Large Arabic RTL headings
- Limited palette
- One central idea per slide
- Diagrams instead of long paragraphs
- Narrative progression: problem/question → explanation → mechanism → example → risk → conclusion/application
- Arabic content mixed carefully with English technical terms
- Consistent safe margins and small footer/signature

## Operating modes

### Image-First Mode

Use when visual polish and consistent rendered slides matter more than editability.

### Editable Native Mode

Use when the final PowerPoint must retain editable text boxes, diagrams, shapes, and native slide elements.
