# Security Policy

## Supported version

Only the latest commit on `main` is actively maintained.

## Reporting a vulnerability

Do not publish credentials, access tokens, private account data, or exploit details in a public issue.

Use GitHub's private vulnerability-reporting option when available. Otherwise, open a minimal public issue requesting a private contact channel without including sensitive details.

If a credential is exposed, revoke or rotate it immediately, remove it from current files and logs, and store replacements in environment variables or GitHub Secrets.
